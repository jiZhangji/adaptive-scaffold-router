项目名称：Adaptive Minimal-Scaffold Routing

一、背景

GRPO 根据最终答案是否正确训练模型。
当一道题的一组答案全部错误时，奖励全部为零，模型无法从这道题中学习。

Scaf-GRPO 通过逐渐加入知识提示、规划提示和步骤提示，帮助模型产生正确答案，恢复训练信号。

二、问题

Scaf-GRPO 需要依次尝试多级提示，生成成本较高。
不同问题需要的提示强度也不同，提示过强还可能让模型依赖提示。

三、挑战

1. 判断哪些问题真正需要提示。
2. 判断问题需要哪一级提示。
3. 减少逐级尝试提示的生成次数。
4. 保证模型最终能够脱离提示独立作答。
5. 保证提示选择策略可以泛化到新的数学问题。

四、动机

训练一个轻量 scaffold router，直接预测：

无需提示 / 知识提示 / 规划提示 / 步骤提示

这样可以减少逐级搜索，只给模型必要的帮助，在恢复困难样本训练信号的同时降低生成成本和提示依赖。

五、简单实验

第一步，让模型无提示回答数学题。

第二步，如果回答错误，依次加入知识提示、规划提示和步骤提示。

第三步，记录模型第一次回答正确时的提示等级，把它作为该问题的最小有效提示标签。

第四步，使用这些标签训练一个四分类 router。

第五步，比较两种方法：

1. 逐级搜索提示。
2. Router 直接选择提示等级。

主要比较正确率、模型调用次数、生成 token 数和运行时间。

六、可行性分析

1. 最小验证实验：可行性高

当前代码已经可以运行无提示、全提示和逐级提示三种策略，并记录最小有效提示等级。
这一阶段不需要强化学习，只需要模型推理，因此实现简单，适合先验证核心假设。

2. Router 训练：可行性较高

Router 本质上是一个四分类器，可以使用题目文本、模型置信度或初始回答作为输入。
训练成本远低于完整大模型强化学习，适合使用 1.5B 左右的数学模型开展实验。

3. 接入 Scaf-GRPO：可行性中等

需要修改 GRPO 的 rollout 流程，在全零奖励时调用 router 并重新生成答案。
方法逻辑清楚，但需要准备分级提示数据，并需要多卡环境运行强化学习训练。

4. 主要风险

最小提示等级会受到采样随机性和提示质量影响。
Router 可能只学习题目长度或关键词，而不是真实能力缺口。
随着模型训练，原来的提示等级标签可能失效，需要定期更新。

七、总体判断

这个方向适合作为一个逐步推进的研究项目。

建议先完成最小提示标签收集和 router 实验，证明 router 可以在保持正确率的同时减少提示调用。
如果这一结果成立，再将 router 接入 Scaf-GRPO，开展完整强化学习实验。
